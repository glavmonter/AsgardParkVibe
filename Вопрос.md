# Въездная стойка

## Сервисы


### Сервис "Шлагбаум", Barrier

Запросы:

- Открыть
- Закрыть

Запросы возвращают результат: BarrierStatus

Связи:

- Hosted worker ISlave, который непосредсвенно даёт команду на шлагбаум

### Сервис "Светофор", Lighth

Запросы:

- Переключить цвет: красный, зеленый, оба горят, никто не горит.

Запросы возвращают результат: LightStatus

Связи:

- Hosted worker ISlave, который непосредсвенно даёт команду на светофор

### Сервис чтения карт Mifare

Запросы:

- Начать поиск карты
- Остановить поиск карты
- Записать карту
- Остановить запись карты

Запросы возвращают результат: MifareStatus

Асинхронный ответ от сервиса:

- Карта прочитана. Отправляется при активном состоянии "поиск карты". В данных считанная карта

Связи:

- Hosted worker IMifareReader, который непосредсвенно даёт команду на аппаратуру

### Сервис "Проверка прав доступа"

Запросы:

- Проверить права для клиента с номером "ClientNumber". Ответ - результат проверки

Связи:

- Их нет, доступ только к БД, проверка записей

### Сервис "Проверка задолжности"

Запросы:

- Посчитать задолжность для клиента с номером "ClientNumber". Ответ - decimal с задолжностью

Связи:

- Их нет, доступ к БД, математика

### Сервис "Детектирование автомобиля"

Запросов к сервису нет.

Генерирует события:

- Автомобиль подъехал к шлагбауму
- Автомобиль уехал от шлагбаума
- Автомобиль проехал через шлагбаум полностью
- Автомобиль заехал за шлагбаум, но уехал назад

Связи:

- Скорее их нет. Сигналы оборудования обрабатывает ISlave и формирует данные события.

### Общие события от сервисов ISlave, IMifareReader

Сервисы, имеющие связи с внешними приборами формируют события изменения их HealthStatus.

В зависимости от состояния аппаратуры должны отображаться различные уровни отказов: мягкий или аварийный

### Таймауты

Некоторые события нужно ожидать с таймаутом. Предусмотреть механизм

## Пример работы

В начале система ожидает сигнала "Автомобиль подъехал к шлагбауму".
При этом событии переключаем светофор в красный, начинаем поиск карты.
Если карты прочитана верно, то проверяем права доступа. Если доступ разрешен, то открываем шлагбаум, если нет, то пишем доступ запрещен. После открытия шлагбаума ожидаем события "Автомобиль проехал через шлагбаум полностью" или "Автомобиль заехал за шлагбаум, но уехал назад" и закрываем шлагбаум.
